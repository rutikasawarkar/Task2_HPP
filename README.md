# House Price Prediction Using Machine Learning

This project focuses on building an end-to-end predictive analysis solution to estimate house prices using machine learning techniques. The objective was to develop a regression model capable of predicting housing prices based on multiple property-related features and to demonstrate the complete machine learning workflow, including data preprocessing, feature selection, model training, and evaluation.

The dataset used in this project contained both numerical and non-numerical attributes such as dates and location details. During the data preprocessing stage, non-numeric columns like date and address-related features were handled appropriately to ensure compatibility with machine learning algorithms. Missing values were identified and treated using statistical methods to maintain data consistency and quality. Exploratory Data Analysis (EDA) was performed to understand feature distributions and correlations, helping identify key factors influencing house prices.

Feature selection was carried out to retain the most relevant predictors and reduce noise in the dataset. The cleaned dataset was then split into training and testing sets using an 80-20 ratio to evaluate the model’s generalization performance. A Linear Regression model was implemented as the baseline predictive algorithm due to its simplicity, interpretability, and effectiveness for continuous target variables.

Model performance was evaluated using standard regression metrics such as Mean Absolute Error (MAE), Root Mean Squared Error (RMSE), and R² score. These metrics provided insights into prediction accuracy and explained variance. The results demonstrated that the model was able to capture key relationships between property features and house prices, achieving satisfactory predictive performance.

This project strengthened my understanding of predictive modeling, data preprocessing, and evaluation techniques, and showcased my ability to translate raw data into actionable insights using Python and machine learning libraries such as Pandas, NumPy, and scikit-learn.
